# External document references

Raw external PDFs are not bundled with the project. These links identify optional
manual recognition/OCR inputs; automated tests construct their own safe fixtures.
Consult each source for current content and reuse terms.

| Document | Source / attribution |
|---|---|
| Blank declaration/control document | [Sabancı IRO](https://iro.sabanciuniv.edu/sites/iro.sabanciuniv.edu/files/2024-06/Declaration%20Control%20Document.pdf) |
| Blank residence-permit application | [Presidency of Migration Management, e-Ikamet](https://e-ikamet.goc.gov.tr/Ikamet/BasvuruFormuOrnegi/BasvuruFormuBos?tur=0); also recorded in `knowledge/sources.json` |
| Norwegian passport specimen | [Government specimen via Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Norwegian_Passport_Specimen.jpg) |
| German passport specimen (expired example) | [Bundesministerium des Innern via Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Mustermann_Reisepass_2007.jpg) |
| Istanbul Airport entry stamp | [Photo by aveaoz, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Entry_stamp_at_Istanbul_Airport.jpg) |
| Istanbul entry stamp (noisy scan) | [Photo by Webshark25, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Istanbul_entry_stamp.jpg) |

Private passports, insurance policies, student certificates, receipts and filled
forms belong only in ignored `data/local_samples/`. Public synthetic examples are
provided as TXT fixtures in `data/synthetic_samples/`.
