Requirements recorded from this source:
- R001 (exchange_stay_requires_ikamet): Incoming Sabancı exchange students staying 3 months or longer enter the residence-permit workflow.
- R002 (permit_type_short_term): For the scoped Sabancı incoming exchange-student case, the workflow uses a short-term residence permit.
- R003 (application_after_entry): A first application is started only after entry into Türkiye; Sabancı instructs entry with passport.
- R004 (apply_before_legal_stay_expiry): The online first application must be completed before visa/visa-exemption/current legal stay expires.
- R006 (passport_validity_buffer): Passport validity must extend at least 60 days beyond the requested residence-permit end date.
- R008 (passport_copy_pages_complete): Required passport copy pages must be present; Sabancı also requires the Türkiye entry page and visa page if applicable.
- R014 (student_certificate_present): Sabancı requires a current student certificate in the file.
- R015 (insurance_covers_period): Health-insurance coverage must cover the requested permit period unless a valid official exemption/alternative applies. The milestone-1 app also used a code-only 'scoped' variant; it was dropped on 2026-11-18 (docs/migration_plan.md).
- R017 (address_proof_sabanci): For Sabancı operational submission, accepted address proof is dorm certificate, rental agreement, or notarized undertaking; Airbnb alone is not accepted. Government also recognizes other cases; outside this scoped workflow they should trigger manual verification.
- R020 (core_file_complete): The core Sabancı submission file must be complete before physical IRO submission.
- R022 (fingerprint_gi_required): After online application, fingerprint/GI processing and a GI number are required in the Sabancı workflow.
- R026 (missing_documents_block_iro): Sabancı IRO does not accept files with missing required documents.
- R027 (additional_documents_possible): Migration authorities may request additional information/documents; complete initial file does not guarantee approval.
- R028 (migration_is_final_authority): Final evaluation/approval belongs to Migration Management, not Sabancı IRO.
- R029 (track_after_submission): After IRO submission, application status should be tracked through official e-İkamet.
